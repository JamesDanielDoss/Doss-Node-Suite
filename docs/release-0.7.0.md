# Doss Node Suite 0.7.0

Expansion candidate for the existing MIT-licensed `jamesdossai/doss-node-suite` package.

- 25 additional processing nodes across images, masks, video/audio, prompts, generation, workflow, and output; 33 tools including Label Maker.
- Optional Doss Hub with search, favorites, user presets, guides, examples, model inventory, diagnostics, and undoable canvas changes.
- Ordered Multi-LoRA controls, labeled image comparison with two pass-through outputs, and optional image/video run records.
- Captured 0.3.2 and 0.6.0 compatibility contracts, processing regressions, frontend harnesses, and executable category examples.
- Compiled frontend assets and declared dependencies included; no model download or runtime package installation.

See [validation](validation-0.7.0.md) for actual tested coverage and limitations. Registry publication remains gated on resolving the existing 0.6.0 review. Do not describe this candidate as an active Registry release until delivery is verified.
